# ProFutbik / Promyachik — START HERE FOR NEW AI

Дата актуализации: 23 июля 2026 года.

## Главное

Это действующий Windows/Hugo-проект футбольной трансферной платформы. Пользователь Дмитрий не вносит обычные технические правки вручную. Работа ведётся итерациями:

1. ИИ готовит AutoSync-совместимый ZIP.
2. ZIP скачивается в `C:\Users\Dmitrii\ProFutbik\Inbox`.
3. AutoSync распаковывает пакет в `C:\Users\Dmitrii\Promyachik`.
4. Пользователь запускает BAT из корня распакованного пакета двойным щелчком.
5. BAT/PowerShell/Python меняет активный проект `C:\Users\Dmitrii\Promyachik_CLEAN` или выполняет диагностику.
6. Скрипт создаёт report в `C:\Users\Dmitrii\ProFutbik\reports`.
7. Пользователь отправляет report или ZIP с отчётами в чат.
8. Следующий пакет строится только по реальному отчёту и текущим файлам.

Не просить пользователя вручную искать и редактировать код в VS Code, если это можно сделать пакетом.
