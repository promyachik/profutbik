{{- /* PF531F: короткое имя игрока для списков. Правило Дмитрия: если имя двойное, в списке печатаем только первую его часть и фамилию. «Jean-Philippe Mateta» становится «Jean Mateta». Зачем: ячейка в колонке фиксированной ширины, и двойное имя уходило в многоточие — «Jean-Philippe Mat…». Обрезанная фамилия хуже сокращённого имени: по ней игрока не узнать. Трогаем только ПЕРВОЕ слово. Двойная фамилия — «Fernandez-Pardo», «Norton-Cuffy» — остаётся целой: это и есть фамилия, резать её нельзя. Полное имя при этом никуда не девается: заголовок страницы, title и описание строятся отдельно и остаются полными — сокращение живёт только в списках. Принимает строку с именем, отдаёт строку. */ -}} {{- $name := . -}} {{- $parts := split $name " " -}} {{- if gt (len $parts) 1 -}} {{- $first := index $parts 0 -}} {{- if in $first "-" -}} {{- $name = printf "%s %s" (index (split $first "-") 0) (delimit (after 1 $parts) " ") -}} {{- end -}} {{- end -}} {{- $name -}}
