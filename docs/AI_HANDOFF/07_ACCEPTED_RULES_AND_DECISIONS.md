# ACCEPTED RULES AND DECISIONS

## Публичный контент

- Имена игроков — латиницей: `Mario Gila`, `Rafael Leão`, `Denzel Dumfries`.
- Сумму трансфера не выдумывать.
- Без достоверного источника не отмечать событие как подтверждённое.
- Технические source URL и внутренние поля не выводить пользователю.

## Фото и art

- Player photo и concept art — разные assets.
- Player photo используется в ticker/profile/card.
- Concept art используется в hero/featured.
- Для ticker/player photo нужен чистый чёрный фон `#000000`, совпадающий с лентой.
- Не использовать генератор изображений для имитации прозрачного PNG.
- Не использовать внешние генераторы/платные сторонние API без явного решения пользователя.
- Не показывать generated art в чат вместо доставки в предусмотренный pipeline/admin flow.

## Тикеры

- Верхний ticker содержит события разных статусов, кликабелен, поддерживает движение и drag.
- Нижний ticker предназначен прежде всего для официальных сделок, но подключается отдельной стадией.
- Не ломать seamless loop.
- Не переписывать ticker с нуля ради одного статуса.

## Страницы и данные

- Каждый новый transfer имеет свой slug и страницу.
- Не подменять старый slug новыми данными.
- Не трогать страницу Denzel Dumfries при slider-задачах.
- Не показывать статистику, если реальных данных нет; не выводить прочерки/пустые заглушки.
- Максимум пять последних клубов в market value history.

## Изменения и backups

- Источник истины — фактический текущий проект и последний report.
- Ошибочные побочные изменения должны быть полностью возвращены в следующем исправляющем пакете.
- Полный backup только после подтверждения шага.
- До подтверждения — минимальная правка, report, точечный rollback.
